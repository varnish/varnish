# bin/vinyld/storage/ — AGENTS.md

Implements pluggable object storage.

The **stevedore** (`struct stevedore`, `STEVEDORE_MAGIC 0x4baf43db`, defined in `storage.h`) is a vtable:

```c
struct stevedore {
    /* required */
    storage_allocobj_f  *allocobj;   /* allocate storage for an object */
    /* optional */
    storage_open_f      *open;
    storage_close_f     *close;
    storage_baninfo_f   *baninfo;    /* notify of ban changes */
    storage_banexport_f *banexport;
    storage_panic_f     *panic;
    storage_allocbuf_f  *allocbuf;   /* for H2 / transient buffers */
    storage_freebuf_f   *freebuf;
    /* SML helpers (if using Simple Memory Layout) */
    sml_alloc_f         *sml_alloc;
    sml_free_f          *sml_free;
    sml_getobj_f        *sml_getobj;
    /* optional LRU */
    struct lru          *lru;
};
```

Built-in user-selectable backends (selected with `-s type,options`):
- `storage_malloc.c` — heap allocation (`-s malloc,<size>`, default)
- `storage_file.c` — mmap'd file (`-s file,<path>,<size>`)
- `storage_persistent.c` — survives restarts, experimental (`-s persistent,...`)
- `storage_umem.c` — Solaris umem allocator
- `storage_debug.c` — debug backend

**SML** (Simple Memory Layout): shared infrastructure used by malloc and file backends. Provides `sml_alloc`/`sml_free`/`sml_getobj` implementations.

Special internal stevedores (not user-selectable):
- `stv_transient` — scratch storage for synthetic responses (`return(synth)`)
- `stv_h2_rxbuf` — HTTP/2 receive buffer pool

VCL variables exposed by stevedore backends are defined via `include/tbl/vrt_stv_var.h` (build-generated by `lib/libvcc/generate.py` — not a static file checked into a fresh checkout).

## Add a storage backend

Implement `struct stevedore` with at minimum `allocobj`. Register with `STV_Register(&my_stevedore, "name")` in `bin/vinyld/storage/mgt_stevedore.c`.
